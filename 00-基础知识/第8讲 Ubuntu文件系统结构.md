# 第8讲 Ubuntu文件系统结构

> 来源：正点原子官方笔记整理

## 一、根目录 `/`

Linux 下 `/` 表示根目录，所有目录都从根目录衍生出来。

## 二、Ubuntu 文件系统结构

| 目录 | 作用 |
| ---- | ---- |
| `/bin` | 存放二进制可执行文件，单用户模式下也能使用，可被 root 和普通用户使用 |
| `/boot` | 存放 Ubuntu 内核和启动文件，例如 `vmlinuz-xxx`，也包含 GRUB 引导相关文件 |
| `/dev` | 存放设备文件 |
| `/etc` | 存放系统配置文件，例如用户账号、密码文件、服务配置等 |
| `/home` | 普通用户主目录默认位置 |
| `/lib` | 存放库文件 |
| `/media` | 可插拔设备挂载目录，例如 SD 卡、U 盘 |
| `/mnt` | 用户可使用的临时挂载点 |
| `/opt` | 可选软件和第三方程序存放目录 |
| `/root` | root 用户主目录 |
| `/sbin` | 存放系统管理相关二进制命令，通常用于系统启动和维护 |
| `/srv` | 服务相关目录，例如网络服务数据 |
| `/sys` | 虚拟文件系统，用于记录内核和设备信息 |
| `/tmp` | 临时目录 |
| `/var` | 存放变化频繁的文件，例如日志文件 |
| `/usr` | Unix Software Resource，存放与系统用户和软件相关的文件，通常占用较大空间 |
| `/proc` | 虚拟文件系统，数据位于内存中，存放系统运行信息 |

## 三、绝对路径和相对路径

- 绝对路径：从根目录 `/` 开始的路径。
- 相对路径：相对于当前目录的路径，不以 `/` 开头。

示例：

```text
./home/zzk
```

特殊路径：

| 写法 | 含义 |
| ---- | ---- |
| `.` | 当前目录 |
| `./` | 当前目录 |
| `..` | 上一层目录 |
| `../` | 上一层目录 |
