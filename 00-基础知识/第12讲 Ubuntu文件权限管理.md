## 一、Ubuntu / Linux 文件权限

文件权限指不同用户或用户组对某个文件拥有的访问能力。

常见权限：

| 权限 | 含义 | 数值 |
| ---- | ---- | ---- |
| `r` | 读 | 4 |
| `w` | 写 | 2 |
| `x` | 可执行 | 1 |

文件描述形式如下：

![image1.png](../assets/images/第12讲Ubuntu文件权限管理/image1.png)

示例：

```text
-rw-rw-r--
```

说明：

- 第一位表示文件类型。
- 后面每三位表示一组权限。
- 三组权限分别对应：拥有者权限、拥有者所在组权限、其他用户权限。

对于 `a.c`：

```text
-rw-rw-r--
```

含义是：

| 对象 | 权限 |
| ---- | ---- |
| 文件所属用户 | 可读、可写、不可执行 |
| 所属用户组内其他用户 | 可读、可写、不可执行 |
| 其他用户 | 只读 |

## 二、Ubuntu / Linux 文件权限修改

| 操作 | 命令 |
| ---- | ---- |
| 修改文件权限 | `chmod` |
| 修改文件所属用户 | `chown` |
