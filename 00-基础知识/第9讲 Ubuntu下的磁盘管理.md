# 第9讲 Ubuntu下的磁盘管理

> 来源：正点原子官方笔记整理

## 一、Ubuntu 磁盘文件

`/dev/sd*` 文件是磁盘设备文件，不能直接当普通文件访问。磁盘必须挂载到某个目录后，才能访问其中的数据。

示例：

| 设备文件 | 含义 |
| ---- | ---- |
| `/dev/sdb` | U 盘设备 |
| `/dev/sdb1` | U 盘第一个分区 |

## 二、磁盘和目录容量查询命令

| 命令 | 作用 |
| ---- | ---- |
| `df` | 列出文件系统整体磁盘使用量，主要查看各文件系统的使用情况 |
| `du` | 评估文件或目录的磁盘使用量，主要查看单个文件或目录大小 |

## 三、磁盘挂载、卸载、分区和格式化

### 3.1 磁盘挂载和卸载

常用命令：

```bash
mount
umount
```

### 3.2 磁盘分区

常用命令：

```bash
fdisk
```

### 3.3 磁盘格式化

磁盘分区创建完成后，可以使用 `mkfs` 格式化分区。

示例：

```bash
mkfs -t vfat /dev/sdx
```
