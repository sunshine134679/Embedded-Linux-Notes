# 第18讲 shell脚本入门

> 来源：正点原子官方笔记整理

## 一、什么是 Shell 脚本

平时可以在终端中一条一条输入命令完成操作。如果需要连续执行很多命令，可以把这些命令写到一个文件中，再直接运行这个文件。这就是 Shell 脚本。

Shell 脚本类似 Windows 的批处理文件，本质上是把连续执行的命令写成一个文件。

Shell 脚本提供数组、循环、条件判断等功能。作为嵌入式开发人员，先掌握基础用法即可。

## 二、Shell 脚本写法

Shell 脚本是纯文本文件，命令从上到下一行一行执行。常见扩展名为 `.sh`。

脚本第一行通常为：

```bash
#!/bin/bash
```

表示使用 Bash 执行脚本。

## 三、Shell 脚本语法

### 3.1 第一个 Shell 脚本

编写 `.sh` 文件，并在文件中写入要执行的命令。

### 3.2 交互式 Shell 脚本

使用 `read` 读取用户输入。

### 3.3 Shell 脚本数值计算

Shell 只支持整型计算，数值计算使用：

```bash
$((表达式))
```

### 3.4 `test` 命令

`test` 命令可以查看文件是否存在、权限等信息，也可以进行数值、字符、文件三类测试。

逻辑执行：

```bash
cmd1 && cmd2
cmd1 || cmd2
```

说明：

- `cmd1 && cmd2`：`cmd1` 执行成功后，才执行 `cmd2`。
- `cmd1 || cmd2`：`cmd1` 执行失败后，才执行 `cmd2`。

### 3.5 中括号 `[]` 判断符

```bash
[ 条件 ]
```

常见比较：

```bash
==
!=
```

### 3.6 默认变量

| 变量 | 含义 |
| ---- | ---- |
| `$0` | Shell 脚本命令本身 |
| `$1` ~ `$n` | 第 1 到第 n 个参数 |
| `$#` | 参数个数 |
| `$@` | 所有参数，即 `$1`、`$2`、`$3` 等 |
