# 第13讲 Linux连接文件

> 来源：正点原子官方笔记整理

## 一、Linux 链接文件

Linux 有两种链接文件：

- 符号链接，也叫软链接，类似 Windows 下的快捷方式。
- 硬链接，通过文件系统的 inode 连接来产生新文件名，而不是产生新文件。

`inode` 用于记录文件属性。一个文件对应一个 inode，inode 相当于文件 ID。查找文件时，系统先找到 inode，再读取文件内容。

## 二、`ln` 命令

`ln` 命令用于创建链接文件：

```bash
ln [选项] 源文件 目标文件
```

常用选项：

| 选项 | 作用 |
| ---- | ---- |
| `-s` | 创建符号链接，也就是软链接 |
| `-f` | 强制创建链接文件；如果目标存在，先删除目标文件，再建立链接 |

## 三、硬链接

硬链接是多个文件名指向同一个 inode。

硬链接特点：

1. 具有相同 inode 的多个文件互为硬链接文件，创建硬链接相当于给文件实体增加入口。
2. 只有删除源文件以及对应的所有硬链接文件后，文件实体才会被删除。
3. 可以通过创建硬链接降低文件误删除风险。
4. 不论修改源文件还是硬链接文件，另一个文件的数据都会改变。
5. 硬链接不能跨文件系统。
6. 硬链接不能链接到目录。

由于限制较多，硬链接并不常用。

## 四、符号链接（软链接）

符号链接类似 Windows 下的快捷方式。软链接使用更频繁。

软链接相当于创建一个独立文件，这个文件会把数据读取指向它链接的目标文件名。

软链接特点：

1. 可以链接到目录。
2. 可以跨文件系统。
3. 删除源文件后，软链接文件会失效。
4. 符号链接文件通过 `->` 指示具体链接目标。
5. 创建符号链接时建议使用绝对路径，否则容易出问题。
