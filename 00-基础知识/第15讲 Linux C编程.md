# 第15讲 Linux C编程

> 来源：正点原子官方笔记整理

## 一、编写 C 程序

可以使用 Vim 编写程序，也可以使用 VSCode。

### 1.1 设置 Vim 编辑器

常见设置：

- 一个 Tab 等于 4 个空格。
- 显示行号。

### 1.2 编写 C 程序

按照 C 语言语法编写源码文件。

## 二、编译 C 程序

使用 GCC 编译器编译 C 程序。

```bash
gcc 源文件.c -o 输出文件
```

## 三、make 工具和 Makefile 文件

`make` 一般指 GNU Make，是一个用于自动化编译的工具，可以把源代码文件编译为可执行二进制文件。

`make` 工具编译时需要 `Makefile` 提供编译规则。

`Makefile` 是 `make` 使用的文件，用于描述编译规则。
