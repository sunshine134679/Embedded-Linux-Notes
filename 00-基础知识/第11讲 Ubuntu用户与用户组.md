# 第11讲 Ubuntu用户与用户组

> 来源：正点原子官方笔记整理

## 一、Linux 用户

Linux 是多用户操作系统。不同用户拥有不同权限，可以查看和操作不同文件。

Ubuntu 常见用户类型：

1. 初次创建的用户。
2. root 用户。
3. 普通用户。

初次创建的用户权限高于普通用户，但低于 root 用户。初次创建的用户可以继续创建普通用户。

用户相关文件：

| 文件 | 作用 |
| ---- | ---- |
| `/etc/passwd` | 记录 Linux 用户信息 |
| `/etc/shadow` | 记录 Linux 用户密码信息 |

每个用户都有一个 ID，称为 UID。

## 二、Linux 用户组

为了方便管理，可以将用户分组。这样就可以设置非本组人员不能访问某些文件。

每个用户可以属于多个不同的组。用户组的目的也是为了控制文件访问权限。

每个用户组都有一个 ID，称为 GID。用户组信息存储在：

```text
/etc/group
```

## 三、创建用户和用户组

### 3.1 图形化界面创建

如果要使用图形化界面创建用户和用户组，需要安装 `gnome-system-tools`：

```bash
sudo apt-get install gnome-system-tools
```

### 3.2 命令行创建

| 操作 | 命令 |
| ---- | ---- |
| 添加用户 | `adduser 用户名` |
| 查询用户 | `finger 用户名` |
| 修改用户密码 | `passwd 用户名` |
| 删除用户 | `deluser 用户名` |
| 添加用户组 | `addgroup 用户组名` |
| 显示组内用户名 | `groups 用户组名` |
| 删除用户组 | `delgroup 用户组名` |
