# 第14讲 vim编辑器

> 来源：正点原子官方笔记整理

## 一、Vim 编辑器

Linux 系统一般自带 `vi` 编辑器，但 `vi` 使用不够方便，建议安装 `vim`。

安装命令：

```bash
sudo apt-get install vim
```

## 二、Vim 三种工作模式

打开文件：

```bash
vi xxx
```

| 模式 | 说明 |
| ---- | ---- |
| 一般模式，也叫指令模式 | 默认模式，用 `vi` 打开文件后自动进入此模式 |
| 编辑模式 | 一般模式下不能直接编辑文件，按 `i`、`I`、`a`、`A`、`o`、`O`、`s`、`r` 等进入编辑模式；按 `Esc` 退出编辑模式 |
| 命令行模式，也叫底行模式 | 先进入一般模式，再输入 `:`、`/`、`?` 中任意一个进入命令行模式 |

查找示例：

```vim
/xxx
```

表示在文件中查找 `xxx`。

## 三、保存退出

| 命令 | 作用 |
| ---- | ---- |
| `:wq` | 保存并退出 |
| `:q` | 退出 |
| `:q!` | 不保存并强制退出 |
| `:w` | 保存 |

## 四、其他常用操作

一般模式下：

| 命令 | 作用 |
| ---- | ---- |
| 方向键 | 控制光标移动 |
| `dd` | 删除光标所在行 |
| `ndd` | 删除光标所在行及其下 `n` 行 |
| `u` | 撤销上一步操作 |
| `.` | 重复前一个操作 |
| `yy` | 复制光标所在行 |
| `nyy` | 复制光标所在行及其下 `n` 行，例如 `10yy` |
| `p` | 粘贴到光标下一行 |
| `P` | 粘贴到光标上一行 |
