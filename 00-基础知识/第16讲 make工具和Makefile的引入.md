# 第16讲 make工具和Makefile的引入

> 来源：正点原子官方笔记整理

## 一、make 工具和 Makefile 文件的引入

当源码文件较多时，不适合每次都手动输入 `gcc` 命令编译。这时需要自动化编译工具。

`make` 一般指 GNU Make，是一个用于自动化编译的软件，可以将源代码文件编译为可执行二进制文件。

`Makefile` 是 `make` 使用的文件，用于指明编译规则。

## 二、编写 C 程序

编写一个包含多个 `.c` 文件的小型 C 程序。

## 三、使用 make 和 Makefile 编译

通过编写 `Makefile` 描述编译目标、依赖关系和命令，再使用 `make` 自动完成编译。
