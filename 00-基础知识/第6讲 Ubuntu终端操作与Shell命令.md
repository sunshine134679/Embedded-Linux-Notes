# 第6讲 Ubuntu终端操作与Shell命令

> 来源：正点原子官方笔记整理

## 一、Ubuntu 终端操作

打开终端后，可以通过命令行完成常见系统操作。

## 二、Shell 常用命令

| 命令 | 作用 |
| ---- | ---- |
| `ls` | 查看目录信息 |
| `cd` | 切换目录 |
| `pwd` | 显示当前路径 |
| `uname` | 查看系统信息 |
| `clear` | 清理终端屏幕 |
| `cat` | 显示文件内容 |
| `sudo` | 以管理员权限执行命令 |
| `cp` | 拷贝文件 |
| `su` | 切换用户 |
| `mv` | 移动或重命名文件 |
| `mkdir` | 创建文件夹 |
| `touch` | 创建文件 |
| `rm` | 删除文件 |
| `rmdir` | 删除空目录 |
| `ifconfig` | 显示网络配置信息 |
| `reboot` | 重启系统 |
| `poweroff` | 关闭系统 |
| `man` | 查看命令帮助 |
| `sync` | 将缓存数据同步写入磁盘 |
| `find` | 查找文件 |
| `grep` | 查找文本内容 |
| `du` | 查看文件夹大小 |
| `df` | 查看磁盘空间 |
| `gedit` | 使用图形编辑器打开文件 |
| `ps` | 查看当前系统进程 |
| `top` | 实时查看进程运行状态 |
| `file` | 查看文件类型 |

`ls -a` 可以显示目录下所有文件和文件夹，包括隐藏文件，例如以 `.` 开头的文件。
