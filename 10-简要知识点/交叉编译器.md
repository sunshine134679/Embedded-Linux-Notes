# 交叉编译（给 ARM 开发板编译程序）

## 一、什么是交叉编译

### 前提（为什么不能直接用 gcc）

**环境**：Windows + WSL 宿主机是 x86_64，ARM 开发板是 ARM 架构，两边通过 NFS 共享根文件系统（rootfs）。

1. **指令集不同**
   宿主机是 x86-64，开发板是 ARM。两者机器码互不兼容：x86 的 CPU 不认识 ARM 指令，ARM 板子也不认识 x86 指令。

2. **gcc 编出来的是 x86 程序，板子跑不了**
   `gcc hello.c -o hello1` 生成的 `hello1` 是 x86-64 的 ELF，拷到开发板上运行会报：
   ```
   Exec format error        （无法识别二进制格式）
   ```

3. **所以需要交叉编译器**
   `arm-linux-gnueabihf-gcc` 运行在 x86 宿主机上，但生成的机器码是 ARM 指令，专门给开发板用。这叫"交叉编译"——编译时用的机器和运行时用的机器不是同一个。

### gcc 与交叉编译器对比

|                    | gcc                         | arm-linux-gnueabihf-gcc  |
| ------------------ | --------------------------- | ------------------------ |
| 运行平台（编译时） | 宿主机 x86_64               | 宿主机 x86_64            |
| 产物架构           | x86-64 ELF                  | ARM ELF (EABI5, armhf)   |
| 动态链接器         | /lib64/ld-linux-x86-64.so.2 | /lib/ld-linux-armhf.so.3 |
| 在哪运行（运行时） | 本机（WSL）                 | ARM 开发板               |

### 名字怎么读

```
arm  -  linux  -  gnueabihf  -  gcc
目标架构    目标系统       工具链类型
  ARM      Linux     GNU EABI + hard-float
```

- **arm**：目标 CPU 是 ARM 架构
- **linux**：目标系统是 Linux
- **gnueabihf**：GNU 工具链 + **hard-float**（浮点参数用硬件 VFP 寄存器传递，要求板子带硬件浮点单元；不带 hf 的 `gnueabi` 是软浮点）

## 二、使用方法

### 基本用法

```bash
arm-linux-gnueabihf-gcc hello.c -o hello1
```

编译完成后，通过 NFS 共享的 rootfs，开发板上直接就能看到并运行：

```sh
./hello1        # 在开发板（/ #）上执行
```

### 静态链接（推荐先试这个）

动态链接的程序运行时需要找板子上的 armhf 动态库（`/lib/ld-linux-armhf.so.3` 和 armhf 版 glibc）。如果板子 rootfs 里没有这些库，运行会报：

```
No such file or directory        （实际是找不到动态链接器/库）
```

解决办法：静态编译，把库一起编进程序，不依赖板子环境：

```bash
arm-linux-gnueabihf-gcc hello.c -o hello1 -static
```

代价是程序体积变大（几百 KB）。

### 针对具体 CPU 优化（可选）

```bash
arm-linux-gnueabihf-gcc hello.c -o hello1 -march=armv7-a -mfpu=neon
```

   正确输出应为 `ELF 32-bit LSB executable, ARM, EABI5 ...`；如果是 `x86-64` 说明用的是普通 gcc，编错了。
   
2. **在宿主机上直接运行 ARM 程序**会报 `Exec format error`，这是正常的，不代表程序坏了。想在本机模拟运行可以用 `qemu-arm ./hello1`。

3. **给板子的程序必须交叉编译**；普通 `gcc` 编的只能在 x86 本机跑。

## 四、总结

1. 交叉编译 = 在 x86 宿主机上编译出 ARM 板子能跑的程序。
2. 命令：`arm-linux-gnueabihf-gcc hello.c -o hello1`。
3. 动态链接在板子上报 "No such file or directory" 时，改用 `-static` 静态编译。
4. 用 `file` 验证产物确实是 ARM 架构。
