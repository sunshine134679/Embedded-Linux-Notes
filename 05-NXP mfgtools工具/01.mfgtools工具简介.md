#  Mfgtools工具简介

## NXP烧写工具

- Mfgtools 是 NXP 官方做的向 i.MX 系列烧写系统的软件，运行在 Windows 下，可以通过 USB 来烧写 uboot.imx、zImage、dtb 和 rootfs 。通过USB烧写
- Mfgtools里面默认存放了NXP官方开发板的系统文件

## 基本原理 

1. 先向开发板的DDR下载一个Linux系统
2. 通过前面下载到DDR中的linux系统完成最终的烧写工作

## 工具文件详情

`"D:\NXP_mfgtool\L4.1.15_2.0.0-ga_mfg-tools\L4.1.15_2.0.0-ga_mfg-tools\mfgtools-with-rootfs\mfgtools\Profiles\Linux\OS Firmware"`  下有 `files` 和 `firmware` 两个文件夹，其中：

- `files` 里面保存着最终烧写到开发板中的uboot.imx、zImage、dtb以及rootfs。
- `firmware` 里面保存着第一步的 uboot.imx、 zImage、dtb。

## 烧写脚本就是各种 “.vbs“ 文件

`"D:\NXP_mfgtool\L4.1.15_2.0.0-ga_mfg-tools\L4.1.15_2.0.0-ga_mfg-tools\mfgtools-with-rootfs\mfgtools"`下有很多 .vbs 文件

- .vbs 脚本的本质是打开 `mfgtools.exe` ，然后跟着一堆的参数，像linux、eMMC、board=sabresd、mmc=1、6uluboot=14x14evk、6uldtb=14x14-evk。以下是 `mfgtool2-yocto-mx-evk-emmc.vbs` 的文件内容：

  ```bash
  Set wshShell = CreateObject("WScript.shell")
  wshShell.run "mfgtool2.exe -c ""linux"" -l ""eMMC"" -s ""board=sabresd"" -s ""mmc=1"" -s ""6uluboot=14x14evk"" -s ""6uldtb=14x14-evk"""
  Set wshShell = Nothing
  ```

##  ucl2.xml文件

`"D:\NXP_mfgtool\L4.1.15_2.0.0-ga_mfg-tools\mfgtools-with-rootfs\mfgtools\Profiles\Linux\OS Firmware\ucl2.xml"`  为ucl2.xml路径

- `uxl2.xml`文件负责在files和firmware里面挑选合适的文件。如果是mx6ull（SD卡启动）的话

  uboot就是：

  - `"file ="firmware/u-boot-imx6ul%lite%%6uluboot%_sd.imx"`，其中：

    - `%lite%` = l；

    - `%6uluboot%` = 14x14evk；

    所以展开就是：

    `"file ="firmware/u-boot-imx6ull14x14evk_sd.imx`

    

  zImage就是：

  - `"firmware/zImage-imx6ul%lite%-%6ulldtb%%ldo%.dtb"`，其中：

    - `%lite%` = l；
    - `%6ulldtb%` = 14x14-evk；
    - `%ldo%`  = ；

    所以展开就是；

    `"file ="firmware/zImage-imx6ull14x14evk.dtb`
