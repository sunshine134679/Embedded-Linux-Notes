# 烧写自己的系统

## 详细步骤

1. 获取烧录时 “firmware“ 目录下要将会被使用文件的文件名（我们所要烧进去的文件，必须要保证名字和对应性质的文件一样）
   - `u-boot-imx6ull14x14evk_emmc.imx` -> uboot文件

   - `zImage` -> zImage文件

   - `zImage-imx6ull-14x14-evk-emmc.dtb` -> dtb文件

     

2. 获取烧录时 “files“ 目录下要将会被使用文件的文件名

   - `u-boot-imx6ull14x14evk_emmc.imx` -> uboot文件
   - `zImage` -> zImage文件
   - `zImage-imx6ull-14x14-evk-emmc.dtb` -> dtb文件
   - `rootfs_nogpu.tar.bz2` -> rootfs
