# 第1讲 正点原子官方系统镜像烧写实验

> 来源：正点原子官方笔记整理

## 一、Windows 下使用 OTG 烧写系统

- 在 Windows 下使用 NXP 提供的 `MfgTool` 给开发板烧写系统，需要先将开发板的 `USB_OTG` 接口连接到电脑。
- `MfgTool` 会先向板子下载一个临时 Linux 系统，再通过这个系统完成烧写。
- 使用 OTG 烧写前，先拔出 SD 卡；等 USB OTG 与电脑连接成功后，再插入 SD 卡。
- 系统一般烧写到 NAND 或 EMMC 中。

## 二、Ubuntu 下通过脚本烧写系统

1. 先向 SD 卡烧写一个系统。
2. 使用 SD 卡启动开发板。
3. 启动后在 Linux 中执行脚本，将系统烧写到 EMMC 或 NAND 中。
