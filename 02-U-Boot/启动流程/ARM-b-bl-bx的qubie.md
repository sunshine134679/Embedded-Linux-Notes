# ARM 中 `b`、`bl`、`bx` 的区别

## 1. `b`

`b` 表示普通跳转。

```asm
b label
```

## 2. `bl`

`bl` 在跳转的同时保存返回地址。

```asm
bl s_init
```

## 3. `bx`

`bx` 的跳转地址来自于寄存器。

```asm
bx lr
```

## 4. 区别

| 指令 | 是否跳转 | 是否更新 LR | 目标来源 |
| ---- | -------- | ----------- | -------- |
| `b` | 是 | 否 | 指令中的目标 |
| `bl` | 是 | 是 | 指令中的目标 |
| `bx` | 是 | 否 | 寄存器 |

## 5. 易错点

`b` 并不是用 `LR` 给 `PC` 赋值。

`bl` 才会保存返回地址。

## 6. 总结

> `b` 用于普通跳转，`bl` 常用于函数调用，`bx` 可以跳转到寄存器保存的地址。
