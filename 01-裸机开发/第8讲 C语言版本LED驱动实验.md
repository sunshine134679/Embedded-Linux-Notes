# 第8讲 C语言版本LED驱动实验

> 来源：正点原子官方笔记整理

## 一、C 语言运行环境构建

### 1.1 设置处理器模式

设置 6ULL 处于 SVC 模式。

需要设置 `CPSR` 寄存器的 `bit4:0`，也就是 `M[4:0]`：

```text
10011 = 0x13
```

读写状态寄存器需要用到：

| 指令 | 作用 |
| ---- | ---- |
| `MRS` | 将 `CPSR` 寄存器数据读到通用寄存器 |
| `MSR` | 将通用寄存器的值写入 `CPSR` |

### 1.2 设置 SP 指针

SP 可以指向内部 RAM，也可以指向 DDR。这里将 SP 指向 DDR。

512 MB DDR 地址范围：

```text
0x80000000 ~ 0x9fffffff
```

栈大小：

```text
0x200000 = 2 MB
```

Cortex-A7 栈向下增长，因此将 SP 设置为：

```text
0x80200000
```

### 1.3 跳转到 C 语言

使用 `b` 指令跳转到 C 语言函数，例如 `main`。
