# 第15讲 GPIO中断实验

> 来源：正点原子官方笔记整理

## 一、回顾 STM32 中断系统

### 1.1 STM32 中断向量表

ARM 芯片从 `0x00000000` 开始运行。程序开始位置通常存放中断向量表，中断向量表用于描述中断对应的中断服务函数。

对于 STM32，代码最开始的地址存放堆栈栈顶指针。

### 1.2 中断向量偏移

一般 ARM 从 `0x00000000` 地址开始运行，而 STM32 常见链接首地址为：

```text
0x08000000
```

如果代码从 `0x08000000` 开始运行，需要告诉 SoC 内核新的中断向量表地址，也就是设置中断向量偏移。STM32 中可以通过设置 `SCB->VTOR` 寄存器为新的中断向量表起始地址来完成。

### 1.3 NVIC 中断控制器

NVIC 是 STM32 的中断管理机构，负责：

- 使能和关闭指定中断。
- 设置中断优先级。

### 1.4 中断服务函数

中断服务函数就是中断发生后需要执行的处理逻辑。

## 二、Cortex-A7 中断系统

### 2.1 Cortex-A 中断向量表

Cortex-A 中断向量表有 8 个中断入口，其中重点关注 IRQ。Cortex-A 的中断向量表需要用户自己定义。

### 2.2 中断向量偏移

裸机例程从 `0x87800000` 开始运行，因此需要设置中断向量偏移。

### 2.3 GIC 中断控制器

GIC 类似 STM32 的 NVIC，用于管理 Cortex-A 中断，提供：

- 开关中断。
- 设置中断优先级。

### 2.4 i.MX6U 中断号

为了区分不同中断，引入中断号。

| 中断 ID 范围 | 类型 | 说明 |
| ---- | ---- | ---- |
| `ID0` ~ `ID15` | SGI | 软件生成中断 |
| `ID16` ~ `ID31` | PPI | 私有外设中断 |
| `ID32` ~ `ID1019` | SPI | 共享外设中断，例如按键、串口等 |

6ULL 支持 128 个中断。

### 2.5 中断服务函数编写

需要完成两层处理：

1. 编写 IRQ 中断服务函数。
2. 在 IRQ 中断服务函数中查找并运行具体外设的中断服务函数。

## 三、GIC 中断控制器

GIC 负责处理中断分发、CPU 接口、中断优先级和中断结束通知。

## 四、中断实验编写

### 4.1 编写按键中断例程

`KEY0` 使用 `UART1_CTS` 这个 IO，需要编写 `UART1_CTS` 的中断代码。

### 4.2 修改 `start.S`

需要添加：

1. 中断向量表。
2. 复位中断服务函数。
3. IRQ 中断服务函数。

复位中断服务函数主要内容：

1. 关闭 I Cache、D Cache 和 MMU。
2. 设置处理器 9 种工作模式下对应的 SP 指针。要使用中断，必须设置 IRQ 模式下的 SP 指针。这里直接设置所有模式下的 SP 指针。
3. 清除 BSS 段。
4. 跳转到 C 函数，也就是 `main`。

### 4.3 CP15 协处理器

常用指令：

| 指令 | 作用 |
| ---- | ---- |
| `MRC` | 将 CP15 协处理器中的寄存器数据读到 ARM 寄存器 |
| `MCR` | 将 ARM 寄存器数据写入 CP15 协处理器寄存器 |

`MCR` 指令格式：

```asm
MCR{cond} p15, <opc1>, <Rt>, <CRn>, <CRm>, <opc2>
```

示例：

```asm
MRC p15, 0, r0, c0, c0, 0
```

要关闭 I Cache、D Cache 和 MMU，需要查看 Cortex-A7 参考手册中的 `SCTLR` 寄存器：

| 位 | 作用 |
| ---- | ---- |
| `bit0` | 打开 / 关闭 MMU |
| `bit1` | 控制对齐 |
| `bit2` | 打开 / 关闭 D Cache |
| `bit11` | 控制分支预测 |
| `bit12` | 打开 / 关闭 I Cache |

### 4.4 设置中断向量偏移

将新的中断向量表首地址写入 CP15 协处理器的 `VBAR` 寄存器。

```asm
MCR{cond} p15, <opc1>, <Rt>, <CRn>, <CRm>, <opc2>
MRC p15, 0, r0, c12, c0, 0
MCR p15, 0, r0, c12, c0, 0
```

### 4.5 IRQ 中断服务函数

读取 CP15 的 `CBAR` 寄存器：

```asm
mrc p15, 4, r1, c15, c0, 0
```

`CBAR` 保存 GIC 控制器寄存器组首地址。

GIC 寄存器组偏移：

| 偏移范围 | 含义 |
| ---- | ---- |
| `0x1000` ~ `0x1fff` | GIC 分发器 |
| `0x2000` ~ `0x3fff` | CPU 接口端 |

代码中，`R1` 保存 GIC 控制器 CPU 接口端基地址。读取 CPU 接口端 `GICC_IAR` 寄存器的值并保存到 `R0`，可以从 `GICC_IAR bit9:0` 读取中断 ID。

`system_irqhandler` 是具体中断处理函数，其参数为 `GICC_IAR` 寄存器的值。

`system_irqhandler` 处理完具体中断后，需要将对应中断 ID 写入 `GICC_EOIR` 寄存器。
