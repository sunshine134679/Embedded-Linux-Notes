# 第24讲 SPI实验

> 来源：正点原子官方笔记整理

## 一、SPI 协议详解

SPI 相比 I2C 主要优势：

1. 速度快，最高可达几十 MHz 甚至上百 MHz。
2. 全双工通信。

一个 SPI 接口可以连接多个 SPI 外设。SPI 通过 CS 片选信号选择通信对象，通信前先将目标外设对应 CS 引脚拉低。

ALPHA 开发板通过 `ECSPI3` 连接 6 轴传感器：

| ECSPI3 信号 | IO |
| ---- | ---- |
| `ECSPI3_SCLK` | `UART2_RX` |
| `ECSPI3_MOSI` | `UART2_CTS` |
| `ECSPI3_SS0` | `UART2_TXD` |
| `ECSPI3_MISO` | `UART2_RTS` |

6ULL 一个 SPI 主接口有 4 个硬件片选：

```text
SS0 ~ SS3
```

根据 CPOL 和 CPHA 可以设置 4 种工作模式。一般使用：

```text
CPOL = 0
CPHA = 0
```

## 二、6ULL SPI 接口详解

6ULL 的 SPI 接口叫 ECSPI，支持全双工，主从模式可配置。

4 个硬件片选之外，也可以使用软件片选，这样一个 SPI 接口可连接的外设数量就不再受硬件片选数量限制。

关键寄存器：

| 寄存器 | 作用 |
| ---- | ---- |
| `RXDATA` | 接收数据寄存器 |
| `TXDATA` | 发送数据寄存器 |
| `CONREG` | 配置寄存器 |
| `CONFIGREG` | SPI 模式和信号极性配置 |
| `STATREG` | 状态寄存器 |
| `PERIODREG` | Wait states 和片选延时配置 |

`CONREG` 常用位：

| 位 | 设置 | 作用 |
| ---- | ---- | ---- |
| `bit0` | `1` | 使能 SPI |
| `bit3` | `1` | 向 TXFIFO 写入数据后立即开启 SPI 突发访问 |
| `bit7:4` | 通道主从模式 | `bit7` 对应通道 3，`bit4` 对应通道 0；使用 `SS0` 时设置 `bit4 = 1` |
| `bit19:18` | `00` | 使用 `SS0`，也就是通道 0 |
| `bit31:30` | `7` | 8 bit 突发长度，也就是一个字节 |

`CONFIGREG` 常用位：

| 位 | 设置 | 作用 |
| ---- | ---- | ---- |
| `bit0` | `0` | PHA，串行时钟第一个跳变沿采集数据 |
| `bit4` | `0` | POL，SCLK 空闲时为低电平 |
| `bit8` | `0` | 相关信号配置 |
| `bit12` | `0` | 相关信号配置 |
| `bit16` | `0` | 空闲时数据线为高 |
| `bit20` | `0` | SCLK 空闲时为低 |

`STATREG`：

| 位 | 作用 |
| ---- | ---- |
| `bit0` | TXFIFO 为空；发送前等待该位为 1 |
| `bit3` | RXFIFO 至少有 1 个字数据；接收前等待该位为 1 |

`PERIODREG`：

| 位 | 作用 |
| ---- | ---- |
| `bit14:0` | Wait states 时间，本实验设置为 `0x2000` |
| `bit15` | Wait states 时钟源，设置为 `0` 表示 SPI CLK |
| `bit21:16` | 片选信号延时，可设置 `0` ~ `63`，本实验设置为 `0` |

SPI 时钟设置：

```text
pll3_sw_clk = 480 MHz / 8 = 60 MHz
```

配置：

| 寄存器位 | 设置 | 作用 |
| ---- | ---- | ---- |
| `CSCDR2 bit18` | `0` | ECSPI 时钟源为 60 MHz |
| `CSCDR2 bit24:19` | `0` | 1 分频 |

最终进入 SPI 外设的时钟源为：

```text
60 MHz
```

ECSPI 模块还需要通过 `ECSPI_CONREG` 设置两级分频：

| 位 | 作用 |
| ---- | ---- |
| `bit15:12` | 前级分频，`0` ~ `0xf` 表示 1 ~ 16 分频 |
| `bit11:8` | 二级分频，设置 `2^n` 分频，`n = 0` ~ `15` |

## 三、ICM20608 简介

`ICM20608` 是通过 SPI 接口通信的 6 轴传感器。

## 四、实验程序编写

使用浮点计算时程序卡死，是因为没有开启 6ULL 硬件浮点运算，且编译时没有指定硬件浮点。

解决方向：

1. 开启 6ULL 硬件浮点单元。
2. 编译时指定硬件浮点。
