# 第19讲 串口实验

> 来源：正点原子官方笔记整理

## 一、串口协议简介

串口用于异步串行通信，常用于裸机调试输出和命令交互。

## 二、6ULL UART 原理

常用寄存器：

| 寄存器 | 作用 |
| ---- | ---- |
| `UART_URXD` | 保存串口接收到的数据 |
| `UART_UTXD` | 发送数据寄存器，写入该寄存器即可发送数据 |
| `UART_UCR1` ~ `UART_UCR4` | UART 控制寄存器 |
| `UART_UFCR` | FIFO 和分频相关配置 |
| `UART_UBIR` / `UART_UBMR` | 配合设置波特率 |
| `UART_USR2` | UART 状态寄存器 |

`UART_UCR1` 常用位：

| 位 | 作用 |
| ---- | ---- |
| `bit0` | UART 使能位，`1` 表示使能 |
| `bit14` | 自动检测波特率使能位，`1` 表示使能 |

`UART_UCR2` 常用位：

| 位 | 作用 |
| ---- | ---- |
| `bit0` | 软件复位位，`0` 表示复位 UART |
| `bit1` | 接收使能，设置为 `1` |
| `bit2` | 发送使能，设置为 `1` |
| `bit5` | 数据位设置，`0` 为 7 位，`1` 为 8 位 |
| `bit6` | 停止位设置，`0` 为 1 位，`1` 为 2 位 |
| `bit7` | 奇偶校验选择，`0` 为偶校验，`1` 为奇校验 |
| `bit8` | 校验使能，`0` 表示关闭校验 |

注意：

```text
UART_UCR3 bit2 必须为 1
```

UART 时钟：

- `UART_UFCR bit9:7` 设置分频值。
- UART 时钟源为 `PLL3 / 6 = 480 MHz / 6 = 80 MHz`。
- `CSCDR1.UART_CLK_SEL = 0` 时，UART 时钟源为 80 MHz。
- `CSCDR1.UART_CLK_SEL = 1` 时，UART 时钟源为 24 MHz 晶振。
- `CSCDR1.UART_CLK_PODF` 控制分频，一般设置为 1 分频，因此 `UART_CLK_ROOT = 80 MHz`。

波特率由以下寄存器共同决定：

- `UART_UFCR`
- `UART_UBIR`
- `UART_UBMR`

`UART_USR2` 常用位：

| 位 | 作用 |
| ---- | ---- |
| `bit0` | 为 `1` 表示有数据可读 |
| `bit3` | 为 `1` 表示数据发送完成 |

## 三、实验程序编写

UART1 引脚：

| 信号 | IO |
| ---- | ---- |
| `UART1_TXD` | `UART1_TX_DATA` |
| `UART1_RXD` | `UART1_RX_DATA` |

注意事项：

1. 编译 `putc` 和 `puts` 时可能提示报错，需要在 `Makefile` 中添加：

   ```make
   -fno-builtin
   ```

2. SecureCRT 打开后串口接收到乱码，可能是编码问题。Linux 默认使用 UTF-8，需要将 SecureCRT 编码模式设置为 UTF-8。
3. 移植的 `printf` 不支持浮点计算和浮点输出。
