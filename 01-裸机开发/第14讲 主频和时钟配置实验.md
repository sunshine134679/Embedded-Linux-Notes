# 第14讲 主频和时钟配置实验

> 来源：正点原子官方笔记整理

## 一、硬件原理图分析

开发板上有两类关键晶振：

1. `32.768 kHz` 晶振，供 RTC 使用。
2. `24 MHz` 晶振，连接到 6U 的 `T16` 和 `T17` 两个 IO。

## 二、i.MX6U 系统时钟分析

### 2.1 7 路 PLL

6ULL 从 24 MHz 晶振生成 7 路 PLL，其中部分 PLL 还会派生 PFD。

| PLL | 作用 |
| ---- | ---- |
| PLL1 | ARM PLL，供给 ARM 内核 |
| PLL2 | System PLL，528 MHz，分出 `PLL2_PFD0` ~ `PLL2_PFD3` |
| PLL3 | USB1 PLL，480 MHz，分出 `PLL3_PFD0` ~ `PLL3_PFD3` |
| PLL4 | Audio PLL，主要供音频使用 |
| PLL5 | Video PLL，主要供 RGB LCD 等视频相关外设使用 |
| PLL6 | ENET PLL，主要供网络外设使用 |
| PLL7 | USB2 PLL，480 MHz，无 PFD |

### 2.2 各路 PLL 分出的 PFD

PFD 用于从 PLL 派生出更多不同频率的时钟。

### 2.3 时钟树

实际配置外设时钟时，需要结合参考手册中的时钟树分析。

### 2.4 外设如何选择合适时钟

以 ESAI 为例，可选时钟源包括：

- `PLL4`
- `PLL3_PFD2`
- `PLL5`
- `PLL3`

### 2.5 要初始化的 PLL 和 PFD

常见初始化对象：

- `PLL1`
- `PLL2` 及 `PLL2_PFD0` ~ `PLL2_PFD3`
- `PLL3` 及 `PLL3_PFD0` ~ `PLL3_PFD3`

一般按照时钟树中的目标值进行设置。

## 三、i.MX6U 系统配置

### 3.1 系统主频配置

目标：设置 ARM 内核主频为 528 MHz。

配置思路：

1. 设置 `CACRR` 寄存器的 `ARM_PODF` 位。

   `ARM_PODF` 位于 `CACRR bit3:0`，可设置 `0` ~ `7`，分别对应 1 ~ 8 分频。这里应设置 `ARM_PODF = 1`，也就是 2 分频。

2. 设置 `PLL1 = 1056 MHz`。

   `PLL1 = pll1_sw_clk`。`pll1_sw_clk` 有两路来源：

   | 来源 | 说明 |
   | ---- | ---- |
   | `pll1_main_clk` | PLL1 主时钟 |
   | `step_clk` | 临时时钟 |

   通过 `CCSR` 寄存器的 `pll1_sw_clk_sel` 位，也就是 `bit2` 选择：

   | `bit2` | 选择 |
   | ---- | ---- |
   | `0` | `pll1_main_clk` |
   | `1` | `step_clk` |

3. 修改 PLL1 前，需要先把 `pll1_sw_clk` 切换到 `step_clk`。

4. 设置 `step_clk`。

   `step_clk` 也有两路来源，由 `CCSR` 的 `step_sel` 位，也就是 `bit8` 设置。为 `0` 时，`step_clk` 来自 `osc = 24 MHz`。

5. 修改 PLL1 频率。

   通过 `CCM_ANALOG_PLL_ARM` 寄存器的 `DIV_SELECT` 位，也就是 `bit6:0` 设置 PLL1 频率：

   ```text
   Output = fref * DIV_SEL / 2
   1056 = 24 * DIV_SEL / 2
   DIV_SEL = 88
   ```

   因此设置：

   ```text
   DIV_SELECT = 88
   ```

   同时设置 `CCM_ANALOG_PLL_ARM` 的 `ENABLE` 位，也就是 `bit13 = 1`，使能输出。

6. 切回 PLL1 前，必须先设置 `CACRR.ARM_PODF = 1`。

### 3.2 各个 PLL 时钟配置

`PLL2` 固定为 528 MHz，`PLL3` 固定为 480 MHz。

初始化 `PLL2_PFD0` ~ `PLL2_PFD3`：

```text
PFD0 = 528 * 18 / PFD0_FRAC
```

例如：

```text
PLL2_PFD0 = 352 MHz
352 = 528 * 18 / PFD0_FRAC
PFD0_FRAC = 27
```

`PLL3_PFD0` ~ `PLL3_PFD3` 也按类似方式初始化。

### 3.3 其他外设时钟源配置

需要配置：

- `AHB_CLK_ROOT`
- `PERCLK_CLK_ROOT`
- `IPG_CLK_ROOT`

因为 `PERCLK_CLK_ROOT` 和 `IPG_CLK_ROOT` 都会用到 `AHB_CLK_ROOT`，所以要先初始化 `AHB_CLK_ROOT`。

**AHB_CLK_ROOT**

目标：

```text
AHB_CLK_ROOT = 132 MHz
```

配置：

1. 设置 `CBCMR.PRE_PERIPH_CLK_SEL`。
2. 设置 `CBCDR.PERIPH_CLK_SEL = 0`。
3. 设置 `CBCDR.AHB_PODF = 2`，也就是 3 分频。

计算：

```text
396 MHz / 3 = 132 MHz
```

**IPG_CLK_ROOT**

设置 `CBCDR.IPG_PODF = 1`，也就是 2 分频。

**PERCLK_CLK_ROOT**

设置 `CSCMR1.PERCLK_CLK_SEL = 0`，表示 `PERCLK` 时钟源为 `IPG`。
