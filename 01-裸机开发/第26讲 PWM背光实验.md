# 第26讲 PWM背光实验

> 来源：正点原子官方笔记整理

## 一、PWM 简介

6ULL PWM 特点：

1. PWM 是 16 位计数器。
2. 有 4 个 16 位 FIFO。
3. 有一个 12 位分频器。
4. 正点原子 LCD 屏幕背光 IO 连接到 `GPIO1_IO08`，该 IO 可复用为 `PWM1_OUT`。

`PWMPR` 寄存器控制 PWM 频率：

- PWM 计数器从 `0x0000` 开始计数。
- 当计数器值等于 `PWMPR + 1` 时，定时器重新开始下一个周期。

FIFO 和采样值：

- FIFO 保存采样值。
- 向 `PWMSAR` 寄存器写采样值时，数据会写入 FIFO。
- 每读取一次 `PWMSAR`，FIFO 数据会减少。
- 或者每产生一个 PWM 信号，FIFO 数据也会减少。
- FIFO 为空后无法继续产生 PWM 信号。
- FIFO 为空时会产生中断，可以在中断中向 `PWMSAR` 写入采样数据。

`PWMCR` 常用位：

| 位 | 设置 | 作用 |
| ---- | ---- | ---- |
| `bit0` | - | PWM 使能位 |
| `bit2:1` | `0` | 每个周期使用 FIFO 中的一个数据 |
| `bit15:4` | `0` ~ `4095` | PWM 分频，表示 1 ~ 4096 分频 |
| `bit17:16` | `1` | 时钟源使用 `ipg_clk = 66 MHz` |
| `bit19:18` | `0` | 相关模式配置 |
| `bit27:26` | `01` | FIFO 空余位置大于 2 时认为 FIFO 为空 |

`PWMIR`：

| 位 | 作用 |
| ---- | ---- |
| `bit0` | 设置为 `1`，开启 FIFO 空中断 |

## 二、实验程序编写

程序重点：

1. 初始化 `GPIO1_IO08` 复用为 `PWM1_OUT`。
2. 配置 PWM 时钟源和分频。
3. 设置 `PWMPR` 控制 PWM 周期。
4. 设置 `PWMSAR` 控制占空比。
5. 通过调整占空比控制 LCD 背光亮度。
