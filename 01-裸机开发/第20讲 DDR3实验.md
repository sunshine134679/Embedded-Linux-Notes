# 第20讲 DDR3实验

> 来源：正点原子官方笔记整理

## 一、DDR 内存简介

### 1.1 RAM 和 ROM

RAM 是易失性存储器，掉电后数据丢失；ROM 通常用于保存不易变更的程序或数据。

### 1.2 SRAM

一开始常用的是芯片内部 RAM。后来因为应用需求，需要外扩 RAM，例如 STM32F103 / F407 可外扩 1 MB SRAM。

示例芯片：

```text
IS62WV51216
```

这是一个 16 位宽、容量 1 MB 的 SRAM。

### 1.3 SDRAM

SDRAM 需要时钟线，常见频率包括：

- 100 MHz
- 133 MHz
- 166 MHz
- 200 MHz

### 1.4 DDR

DDR 在 SDRAM 基础上提高了数据传输效率，是嵌入式 Linux 平台常用外部内存。

## 二、DDR3 时间参数

### 2.1 传输速率

示例：

- DDR3 1600
- DDR3 1866
- DDR4 2400
- DDR4 3200

单位常见为 `MT/s`。

### 2.2 `tRCD`

行地址到列地址的延迟。

### 2.3 CL 参数

CAS Latency，列地址选通延迟。

### 2.4 `tRC`

行周期时间。

### 2.5 `tRAS`

行有效到预充电所需时间。

## 三、i.MX6U MMDC 控制器

MMDC 特点：

1. 多模式支持 DDR3 / DDR3L / LPDDR2，支持 x16 位宽。
2. MMDC 最高支持 DDR3 频率 400 MHz，也就是 800 MT/s。
3. 6ULL 给 DDR 提供专用 IO。

DDR 时钟配置：

```text
MMDC_CLK_ROOT = PLL2_PFD2 = 396 MHz
```

前面例程已经设置为 396 MHz。

相关寄存器配置：

| 寄存器位 | 作用 | 设置 |
| ---- | ---- | ---- |
| `CBCMR.PRE_PERIPH2_CLK_SEL` (`bit22:21`) | 设置 `pre_periph2` 时钟源 | `01`，选择 `PLL2_PFD2` |
| `CBCDR.PERIPH2_CLK_SEL` (`bit26`) | 设置 MMDC 时钟源 | `0`，选择 PLL2 |
| `CBCDR.FABRIC_MMDC_PODF` (`bit5:3`) | 设置 MMDC 分频 | `0`，1 分频 |

最终：

```text
MMDC_CLK_ROOT = 396 MHz
```

## 四、DDR3L 初始化与测试

### 4.1 `ddr_stress_tester` 配置文件

通过 Excel 配置 DDR 参数，Excel 配置完成后，`realview.inc` 会同步更新。

### 4.2 `.inc` 文件

`ddr_stress_tester` 工具需要使用 `.inc` 文件。

### 4.3 测试

`ddr_stress_tester` 通过 USB 口将 `.inc` 中的配置信息下载到开发板中。如果直接进行超频测试，可能会测试失败。

### 4.4 校准

Write leveling calibration：

```text
MMDC_MPWLDECTRL0 ch0 (0x021b080c) = 0x00000000
MMDC_MPWLDECTRL1 ch0 (0x021b0810) = 0x00070007
```

Read DQS Gating calibration：

```text
MPDGCTRL0 PHY0 (0x021b083c) = 0x01380138
MPDGCTRL1 PHY0 (0x021b0840) = 0x00000000
```

Read calibration：

```text
MPRDDLCTL PHY0 (0x021b0848) = 0x40402e32
```

Write calibration：

```text
MPWRDLCTL PHY0 (0x021b0850) = 0x40403432
```
