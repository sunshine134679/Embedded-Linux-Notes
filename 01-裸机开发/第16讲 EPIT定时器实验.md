# 第16讲 EPIT定时器实验

> 来源：正点原子官方笔记整理

## 一、EPIT 简介

EPIT 特点：

1. EPIT 是 32 位向下计数器。
2. EPIT 时钟源可选择，本实验选择 `ipg_clk = 66 MHz`。
3. EPIT 支持时钟分频，12 位分频器，`0` ~ `4095` 分别代表 1 ~ 4096 分频。
4. 开启定时器后，计数寄存器每个时钟减 1；当计数值和比较寄存器值相等时触发中断。
5. 6ULL 有两个 EPIT 定时器。

EPIT 有两种工作模式：

- Set-and-forget
- Free-running

`EPIT_CR` 寄存器用于配置 EPIT。

## 二、实验原理简介

`EPIT_CR` 常用位：

| 位 | 设置 | 作用 |
| ---- | ---- | ---- |
| `bit0` | `1` | 使能 EPIT |
| `bit1` | `1` | 计数器初始值来自加载寄存器 |
| `bit2` | `1` | 使能比较中断 |
| `bit3` | `1` | 工作在 set-and-forget 模式 |
| `bit15:4` | 分频值 | 设置时钟分频 |
| `bit25:24` | `1` | 时钟源选择 `ipg_clock = 66 MHz` |

`EPIT_SR`：

- 只有 `bit0` 有效，表示中断状态。
- 写 `1` 清零。
- `OCIF = 1` 表示中断发生，`OCIF = 0` 表示中断未发生。
- 处理完定时器中断后必须清除中断标志位。

`EPIT_LR`：

- 设置计数器加载值。
- 计数器计时到 0 后，会重新读取 `LR` 寄存器值开始计时。

`CMPR`：

- 比较寄存器。
- 当计数器值和 `CMPR` 相等时产生比较中断。

本实验使用 EPIT 实现 500 ms 周期定时器，在 EPIT 中断服务函数中控制 LED 亮灭。

## 三、实验程序编写

程序重点：

1. 初始化 EPIT 时钟源和分频。
2. 设置加载值和比较值。
3. 使能 EPIT 中断。
4. 在中断服务函数中翻转 LED。
5. 清除中断标志位。
