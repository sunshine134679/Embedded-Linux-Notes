# 第23讲 I2C实验

> 来源：正点原子官方笔记整理

## 一、I2C / IIC 协议详解

ALPHA 开发板上有一个 `AP3216C`，它是 I2C 接口的环境光传感器，连接到 `I2C1`。

引脚连接：

| 信号 | IO | 复用 |
| ---- | ---- | ---- |
| `I2C1_SCL` | `UART4_TXD` | `ALT2` |
| `I2C1_SDA` | `UART4_RXD` | `ALT2` |

I2C 包含两根线：

- `SCL`
- `SDA`

这两根线必须接上拉电阻到 VCC，例如 3.3 V，常用 4.7K 上拉电阻。

I2C 总线支持多从机，通过从机地址区分访问哪个设备。

## 二、6ULL I2C 接口详解

关键点：

1. 6ULL I2C 标准模式频率为 100 kbit/s，快速模式为 400 kbit/s。
2. 时钟源选择：

   ```text
   perclk_clk_root = ipg_clk_root = 66 MHz
   ```

3. `IFDR` 寄存器设置 I2C 频率，`bit5:0` 设置分频值。

如果目标速率为 100 kbit/s：

```text
66000000 / 100000 = 660
```

查表后，当 IC 位设置为 `0x38` 或 `0x15` 时，为 640 分频：

```text
66000000 / 640 = 103.125 kbit/s
```

关键寄存器：

| 寄存器 | 位 | 作用 |
| ---- | ---- | ---- |
| `I2CR` | `bit7` | I2C 使能位，置 1 使能 |
| `I2CR` | `bit5` | 主从模式选择，`0` 从机，`1` 主机 |
| `I2CR` | `bit4` | 发送 / 接收设置，`0` 接收，`1` 发送 |
| `I2SR` | `bit7` | 传输完成位，`0` 正在发送，`1` 发送完成 |
| `I2SR` | `bit5` | I2C 忙闲位，`0` 空闲，`1` 忙 |
| `I2SR` | `bit0` | 读确认位，即 ACK 信号 |
| `I2DR` | - | 数据寄存器 |

## 三、AP3216C 简介

`AP3216C` 是三合一环境光传感器：

- `ALS`：环境光。
- `PS`：接近传感器。
- `IR`：红外 LED。

接口为 I2C，最高频率 400 kbit/s。

基本信息：

| 项目 | 内容 |
| ---- | ---- |
| ALS | 16 位输出 |
| PS | 10 bit 输出 |
| IR | 10 bit 输出 |
| 从机地址 | `0x1e` |

常用寄存器：

| 地址 | 说明 |
| ---- | ---- |
| `0x00` | 系统配置寄存器，`bit2:0` 设置启用哪些传感器；设置为 `0x3` 表示开启 `ALS + PS + IR` |
| `0x0a` | IR Data Low，`bit7 = 0` 表示 IR 和 PS 数据有效，`bit7 = 1` 表示无效；`bit1:0` 为 IR 低 2 位 |
| `0x0b` | IR Data High，`bit7:0` 为高字节，与 `0x0a` 组成 10 bit 数据 |
| `0x0c` / `0x0d` | ALS 低 8 位和高 8 位 |
| `0x0e` / `0x0f` | PS 数据，`0x0e bit3:0` 为低 4 位，`0x0f bit5:0` 为高 6 位，合计 10 位 |
