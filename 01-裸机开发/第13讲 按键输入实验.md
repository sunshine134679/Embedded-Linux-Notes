# 第13讲 按键输入实验

> 来源：正点原子官方笔记整理

## 一、硬件原理图分析

按键 `KEY0` 连接到 `UART1_CTS` 引脚。

| 状态 | `UART1_CTS` 电平 |
| ---- | ---- |
| 默认未按下 | 高电平 |
| 按下 `KEY0` | 低电平 |

## 二、实验程序编写

程序流程：

1. 设置 `UART1_CTS` 复用为 `GPIO1_IO18`。
2. 设置 `UART1_CTS` 的电气属性。
3. 配置 `GPIO1_IO18` 为输入模式。
4. 读取按键值，也就是读取 `GPIO1_IO18` 的高 / 低电平。

## 三、清除 BSS 段后代码不运行的问题

原始 `__bss_start`：

```text
__bss_start = 0x87800289
```

对于 32 位 SoC，一般按 4 字节访问，常见地址对齐形式为：

```text
0x0
0x4
0x8
0xc
```

如果没有按 4 字节对齐，芯片处理时可能从错误地址开始清除 BSS 段。

因此需要让 `__bss_start` 按 4 字节对齐：

```text
__bss_start = 0x8780028c
```
