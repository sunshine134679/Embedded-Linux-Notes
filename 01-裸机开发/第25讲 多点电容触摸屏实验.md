# 第25讲 多点电容触摸屏实验

> 来源：正点原子官方笔记整理

## 一、多点电容触摸屏简介

多点电容触摸屏特点：

1. 支持多点触摸。
2. 不需要按压。
3. 需要一个触摸 IC 控制，一般使用 I2C 接口。
4. 多点触摸屏驱动本质上是一个 I2C 外设驱动。

正点原子电容触摸屏触摸 IC：

| 屏幕 | 触摸 IC |
| ---- | ---- |
| 4.3 寸 | `GT9147` |
| 7 寸其中一款 | `FT5206` |
| 7 寸其中一款 | `FT5426` |

触摸屏接口：

| 信号 | 连接 |
| ---- | ---- |
| `CT_INT` | 触摸中断线，连接到 `GPIO1_IO09` |
| `I2C2_SCL` | 连接到 `UART5_TXD` |
| `I2C2_SDA` | 连接到 `UART5_RXD` |
| `RESET` | 连接到 `SNVS_TAMPER9` |

电容触摸芯片输出的触摸点坐标信息对应屏幕像素点，因此不需要校准；电阻屏需要校准。

## 二、FT54x6 / FT52x6 电容触摸芯片简介

基本信息：

1. I2C 接口，最大 400 kHz。
2. 正点原子 7 寸屏幕 `FT5426` 的 I2C 地址为 `0x38`。

常用寄存器：

| 寄存器 | 地址 | 说明 |
| ---- | ---- | ---- |
| `DEVICE_MODE` | `0x00` | 设置为 `0x0`，表示正常运行模式 |
| `ID_G_LIB_VERSION_H` | `0xa1` | 固件版本号高字节 |
| `ID_G_LIB_VERSION_L` | `0xa2` | 固件版本号低字节 |
| `ID_G_MODE` | `0xa4` | 设置为 `1`，表示采用中断方式上报触摸信息 |
| `TD_STATUS` | `0x02` | 当前触摸点个数，范围 1 ~ 5 |
| `TOUCH1_XH` | `0x03` | 从这里开始记录触摸点坐标信息 |

触摸点数据：

- 一个触摸点占 6 个寄存器。
- 最多 5 个触摸点，共 `5 * 6 = 30` 个寄存器。
- 读取范围一直到 `0x20`。
- 一个触摸点坐标使用 12 bit 表示。
- 坐标高寄存器的 `bit3:0` 为高 4 位，低寄存器 `bit7:0` 为低 8 位。
- 对于 `XH` 寄存器，`bit7:6` 表示事件，非常重要。
- 对于 `YH` 寄存器，`bit7:4` 表示触摸 ID。

## 三、实验程序编写

程序重点：

1. 初始化 I2C2。
2. 初始化触摸中断 IO 和复位 IO。
3. 配置触摸芯片工作模式。
4. 读取触摸点数量和坐标。
5. 将触摸坐标映射到 LCD 显示。
