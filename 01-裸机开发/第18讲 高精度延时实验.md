# 第18讲 高精度延时实验

> 来源：正点原子官方笔记整理

## 一、GPT 定时器简介

以前的延时函数采用空指令实现，延时不准确。修改 6ULL 主频后，空指令延时也会随之变化。因此需要使用不随主频变化的高精度延时函数。

STM32 使用 SysTick 硬件定时器实现高精度延时。6U 中可以使用 GPT 定时器实现类似功能。

GPT 特点：

1. 32 位向上计数器。
2. 支持捕获功能。
3. 支持比较输出或中断功能。
4. 有一个 12 位分频器。
5. 时钟源可选择，本实验使用 `ipg_clk = 66 MHz`。
6. 支持 Restart 和 Free-run 两种工作模式。

工作模式：

| 模式 | 说明 |
| ---- | ---- |
| Restart | 定时器计数值和比较寄存器 `OCR` 相等时，定时器从 0 重新计时；只有比较通道 1 支持此功能 |
| Free-run | 从 0 一直加到 `0xffffffff`，再重新从 0 开始；三个输出比较通道都适用 |

`GPT_CR` 常用位：

| 位 | 作用 |
| ---- | ---- |
| `bit0` | GPT 使能位，`0` 关闭，`1` 使能 |
| `bit1` | 计数器初始值，`0` 表示保留上次关闭值，`1` 表示从 0 开始 |
| `bit8:6` | 时钟源选择，设置为 `1` 表示 `ipg_clk = 66 MHz` |
| `bit9` | 工作模式，`0` 为 Restart，`1` 为 Free-run |
| `bit15` | 软件复位 |

原笔记中 “`GPT_CR bit11:0` 为分频值” 应按 GPT 分频寄存器位理解：可设置 `0` ~ `4095`，表示 1 ~ 4096 分频。

`GPT_SR`：

| 位 | 作用 |
| ---- | ---- |
| `bit5` | 溢出发生 |
| `bit4` | 输入通道 2 捕获中断标志 |
| `bit3` | 输入通道 1 捕获中断标志 |
| `bit2:0` | `OF3` ~ `OF1` 比较中断标志 |

`GPT_IR` 是中断使能寄存器。

## 二、GPT 定时器使用

配置 GPT 时钟源、分频和工作模式后，可以通过读取计数器或使用比较中断实现高精度延时。

## 三、高精度延时原理简介

使用固定时钟源驱动 GPT，通过计数差值判断延时时间。这样延时不依赖 CPU 空转指令，也不直接受主频变化影响。

## 四、实验程序编写

程序重点：

1. 初始化 GPT。
2. 设置时钟源和分频。
3. 读取计数器值。
4. 根据目标延时时间计算等待计数。
5. 封装微秒 / 毫秒延时函数。
