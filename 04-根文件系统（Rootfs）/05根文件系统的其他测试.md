# 根文件系统的其他测试



##  1.测试应用程序的运行

- 编写hello.c，测试软件运行在ARM开发版上，因此编译的时候要使用交叉编译器`arm-linux-gnueabihf-gcc`(在x86架构下编译能够在ARM下运行的文件)，而非`gcc`（编译的产物只能在x86架构下运行）

-  对于编译产物的类型，可以使用`file`命令查看：

  ![image-20260817105539609](D:\Documents\Embedded-Linux-Notes\04-根文件系统（Rootfs）\media\05根文件系统的其他测试\image-20260817105539609.png)
  
  ![image-20260817105737522](D:\Documents\Embedded-Linux-Notes\04-根文件系统（Rootfs）\media\05根文件系统的其他测试\image-20260817105737522.png)

- 应用程序后台运行命令：(xxx代表可运行的程序)

  ```bash
  (记得没在PATH中的应用程序需要加上路径)xxx &
  ```

  想要关闭后台运行，输入`ps`命令查看当前所有软件的`PID`，查到之后，通过

  ```bash
  kill -9 xxx(PID)
  ```

   结束程序运行
