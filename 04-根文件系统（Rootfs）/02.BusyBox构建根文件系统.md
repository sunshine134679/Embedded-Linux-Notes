# BusyBox构建根文件系统

- 构建根文件系统，使用的是`busybox`。还有很多成熟化的根文件系统构建方式，比如`buildroot` `yocto`.
- `busybox`就是一个巨大的工具箱，这个工具箱里面集成了Linux的许多工具和命令，比如ls 、mv、 ifconfig等等。
- 构建的根文件系统调试我们通过`nfs`网络挂载，也就是根文件系统存放到Ubuntu下，开发版启动以后通过`nfs`服务使用Ubuntu下的根文件系统。



## 使用流程

> 具体流程详见用户指南

### 1. 修改Makefile，添加交叉编译器

- 修改ARCH 和 CROSS _COMPILE。



### 2. 让BusyBox支持中文字符



### 3. 配置 Busybox

- ```bash
  make defconfig
  ```

- 打开图形化配置界面

  ```bash
  make menuconfig
  ```



### 4. 编译Busybox

- 需要将busybox编译产出的文件放在``nfs/rootfs/`` 目录下

  ```bash
  make install CONFIG_PREFIX=/home/wsl/Linux/nfs/rootfs/
  ```

  

### 5. 拷贝库文件

- 需要将gcc编译器中的库拷贝到rootfs下(注意替换链接文件)
- 先是rootfs/lib，然后是rootfs/usr/lib
