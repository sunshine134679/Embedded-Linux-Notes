# ARM汇编中 `b`、`bl`、`bx` 的区别

## 一、核心区别

| 指令 | 是否跳转 | 是否更新 LR | 跳转目标来源 | 常见用途 |
| ---- | ---- | ---- | ---- | ---- |
| `b` | 是 | 否 | 指令中写死的标号或地址 | 普通跳转 |
| `bl` | 是 | 是 | 指令中写死的标号或地址 | 函数调用 |
| `bx` | 是 | 否 | 寄存器中的地址 | 函数返回、状态切换 |

## 二、`b`

`b` 表示普通跳转，不保存返回地址。

```asm
b label
```

执行后会直接跳转到 `label`，不会修改 `LR`。

## 三、`bl`

`bl` 表示带链接的跳转，会在跳转前把返回地址保存到 `LR`。

```asm
bl s_init
```

因此 `bl` 常用于函数调用。被调用函数执行结束后，通常可以通过 `LR` 返回。

## 四、`bx`

`bx` 的跳转目标来自寄存器。

```asm
bx lr
```

`bx lr` 常用于函数返回，含义是跳转到 `LR` 保存的地址。

## 五、易错点

- `b` 只是普通跳转，不会把返回地址写入 `LR`。
- `bl` 才会更新 `LR`，所以它常用于函数调用。
- `bx lr` 不是“调用函数”，而是跳转到 `LR` 中保存的地址，常用于返回。
- `b` 不能理解为“把 `LR` 赋值给 `PC`”；真正根据寄存器跳转的是 `bx`。
